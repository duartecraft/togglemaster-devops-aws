# 🧩 12-Factor App — Checklist

| Fator | Evidência a procurar | Status |
|---|---|---|
| Codebase | Repositório Git | A preencher |
| Dependencies | `requirements.txt` | A preencher |
| Config | Variáveis `DB_*` | A preencher |
| Backing services | PostgreSQL local/RDS | A preencher |
| Build, release, run | Imagem e comando Gunicorn | A preencher |
| Processes | Processo Gunicorn | A preencher |
| Port binding | Porta 5000 | A preencher |
| Concurrency | Workers do servidor | A preencher |
| Disposability | Inicialização e encerramento | A preencher |
| Dev/prod parity | PostgreSQL local e RDS | A preencher |
| Logs | Saída do processo | A preencher |
| Admin processes | Migrações ou comandos | A preencher |

## Regra de análise

Não marcar um fator como atendido sem evidência no código, configuração ou execução.
