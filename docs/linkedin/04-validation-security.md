# 🔐 Post 4 — Validação e segurança

## Gancho

Uma API responder HTTP 200 não prova que o deploy está correto.

## Tese

A validação precisa provar saúde, funcionalidade, persistência e controle de acesso.

## Estrutura

1. Health check.
2. CRUD de uma flag.
3. Reinício da aplicação.
4. Confirmação da persistência.
5. Security Groups.
6. Limpeza dos recursos.

## Evidência necessária

Checklist, prints anonimizados e resultado dos testes.
