# 🤝 Contribuindo

## Fluxo recomendado

1. Criar ou atualizar a documentação da fase.
2. Executar o laboratório em ambiente controlado.
3. Registrar comandos, evidências e decisões.
4. Remover segredos e dados sensíveis.
5. Fazer commit pequeno e descritivo.

## Padrão de commit

Use mensagens no formato:

```text
<tipo>: <descrição curta>
```

Tipos sugeridos: `feat`, `fix`, `docs`, `test`, `security`, `refactor`.
